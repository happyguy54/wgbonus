# wgbonus

This project provides a tool for calculating bonuses based on the input text provided by the user. The tool processes the input and displays the results in a structured format.

## Features

- **Input Text Processing**: Enter text data in the provided textarea to process and extract relevant information.
- **Dynamic Table Creation**: Generates a summary and detailed table based on the input data.
- **Links and Actions**: Provides actionable links based on the extracted data.
- **Cookie Management**: Automatically deletes all cookies on page load.

## Usage

1. **Open the Webpage**: Navigate to the `index.html` file in your browser.
2. **Enter Data**: Paste the input text into the textarea provided under "Vložte tabulku pro výpočet bonusu".
3. **Process Data**: Click the "Zpracovat" button to process the input text.
4. **View Results**: The processed data will be displayed in a structured format with links for further actions.

## Scripts

- **script.js**: Contains the logic to process the input text, extract data, and generate the output tables.

## HTML Structure

- **index.html**: The main HTML file which includes the structure of the webpage and links to the necessary scripts and stylesheets.
